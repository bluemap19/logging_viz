# `src_well_data` 综合设计文档

## 1. 模块概述

**目录路径：** `src_well_data/`  
**功能定位：** 测井数据统一管理框架，负责常规测井曲线、电成像（FMI）、核磁共振（NMR）、岩性类型表和岩心实验数据的多格式读取、预处理和统一访问。  
**代码规模：** 约 2,400 行（不含测试代码），9 个 Python 文件。

## 4. 数据流设计

### 4.1 常规测井数据流

```
文件 (CSV/Excel/TXT)
         │
         ▼
   DataLogging.read_data()
         │
         ├─► 多编码回退读取
         ├─► columns_preprocess() — 清理列名（去空格、大写化、去下划线）
         ├─► 计算分辨率 (find_mode(np.diff(depth)))
         │
         ▼
   _data (DataFrame)
         │
         ├──► get_data() — 原始数据 + 曲线名称映射 (input_cols_mapping)
         └──► get_data_normed() — 归一化数据 (惰性)
```

### 4.2 电成像数据流

```
文件 (CSV/TXT/IMAGE)
         │
         ▼
   DataFMI.read_data()
         │
         ├─► CSV: pd.read_csv(index_col=0)
         ├─► TXT: np.loadtxt(skiprows=8)
         └─► IMAGE: cv2.imread() + 从文件名解析深度
         │
         ▼
   (_data_fmi, _data_depth)
         │
         ├──► ele_stripes_delete() — 空白条带删除
         ├──► get_texture() — GLCM 纹理特征 → 缓存 CSV
         ├──► get_fmi_fde() — 分形维数谱 → 缓存 TXT
         └──► fmi_segment() — 图像分割(6种方法) → 缓存 TXT
```

### 4.3 岩心数据流

```
岩心文件 (CSV/Excel/TXT)
         │
         ▼
   DataCore.read_data()
         │
         ├─► 多编码回退读取（csv/txt）
         ├─► columns_preprocess() — 清理列名（去空格、大写化）
         ├─► _validate_data() — 深度单调性验证
         ├─► _calculate_resolution() — 计算采样间隔（平均值，稀疏）
         │
         ▼
   _data (DataFrame)
         │
         ├──► get_data() — 原始数据 + 深度范围筛选
         └──► get_curve_names() — 获取列名列表
```

## 5. 关键设计决策

### 5.1 Facade 模式（DATA_WELL）

`DATA_WELL` 不直接持有数据，而是作为统一入口，按需创建和调用各子模块。对外提供：

- **统一访问**：同一接口获取不同类型数据
- **惰性初始化**：文件路径不在字典中才创建子模块实例
- **单例保证**：同一路径不会重复创建实例
- **关键字搜索**：支持按文件名关键字模糊匹配文件路径

### 5.2 惰性加载

所有数据访问方法（`get_data()`, `get_texture()`, `get_table_2()` 等）均遵循：

```
if not self._is_data_loaded:
    self.read_data()
```

避免文件重复读取，提升性能。

### 5.3 曲线名称映射

测井数据的列名（别名）通过 XML 配置文件集中管理：

```xml
<LogType name="GR">
    <Alias>GRC</Alias>
</LogType>
```

支持多编码读取（CSV 文件尝试 4 种编码回退），提高数据兼容性。

### 5.4 表格格式双向转换

岩性表支持两种格式互转，平衡不同场景需求：

- **2列格式**：每个深度点一行，适合与测井曲线直接对齐
- **3列格式**：每个连续岩性段一行，存储效率高

## 6. 配置说明

### 6.1 曲线映射配置 `COLS_MAPPING.xml`

```xml
<LogAliasMapping>
    <LogType name="depth">  <Alias>#Depth</Alias> ... </LogType>
    <LogType name="GR">     <Alias>GRC</Alias>      ... </LogType>
    <LogType name="DEN">    <Alias>DENC</Alias>     ... </LogType>
    ...
</LogAliasMapping>
```

### 6.2 FMI 纹理计算默认配置

```python
{
    'level': 16,
    'distance': [2, 4],
    'angles': [0, np.pi / 2],
    'windows_length': 200,
    'windows_step': 100
}
```

### 6.3 深度分辨率默认值

| 模块 | 默认分辨率 | 说明 |
|------|-----------|------|
| DataLogging | `0.0025` | 自动从深度差众数计算 |
| DataFMI | `0.0025` | 硬编码 |
| DataNMR | `0.0025` | 硬编码 |
| DataTable | `0.1` | ⚠️ 与测井数据不一致 |
| DataCore | 无 | 稀疏点数据不计算分辨率 |
