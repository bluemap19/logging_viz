# 岩心数据叠加绘制 — 设计文档

## 1. 设计背景与动机

### 1.1 岩心实验数据特点

| 特点 | 说明 |
|------|------|
| **稀疏性** | 大部分深度点为 NaN，仅在取心位置有数据 |
| **珍贵性** | 取心成本高，数据点少但意义重大 |
| **共存储** | 与常规曲线共存于同一 DataFrame 的不同列 |
| **局部性** | 仅在特定深度段出现 |

### 1.2 为什么选择叠加绘制而非独立面板

测井图的道资源有限，新增独立面板会：

- 压缩所有其他面板宽度
- 占用大量空白（岩心数据稀疏）
- 改变已有交互逻辑

**叠加绘制方案优势**：

- ✅ 不占用额外面板资源
- ✅ 与对应曲线在同一道对比阅读
- ✅ 视觉直观，数据关系清晰
- ✅ 对现有架构侵入最小

## 2. 配置格式 — `config_core`

### 2.1 完整配置项

```python
config_core = {
    # ========== 核心配置（必填）==========
    'core_curves': List[str],        # 岩心数据列名（存在于 logging_data）

    # ========== 绘制位置配置 ==========
    'plot_index_list': List[int],   # 叠加绘制在哪几道（曲线道索引，从0开始）
                                      # 长度应与 core_curves 一致
                                      # 未指定时自动均分到各常规曲线道

    # ========== 样式配置 ==========
    'thicknesses_config': List[float],  # 杆粗细（Line2D 线宽），默认 2.0
    'colors_config': List[str],         # 杆颜色（CSS 颜色或 Hex），默认蓝橙序列

    # ========== 坐标轴配置 ==========
    'axis_config': List[bool],          # 坐标轴是否 log 刻度（当前版本未使用）

    # ========== 数据范围配置 ==========
    'range_config': List[List[float]],  # [min, max] 范围，用于归一化
                                        # 未指定时从数据实际 min/max 推断
}
```

### 2.2 配置示例

```python
# 简单场景：仅配置岩心列，其余自动推断
config_core = {
    'core_curves': ['CORE_GR', 'CORE_RT', 'CORE_AC']
}

# 完整场景：显式指定所有参数
config_core = {
    'core_curves': ['CORE_GR', 'CORE_RT'],
    'plot_index_list': [0, 1],  # 第0道画 CORE_GR，第1道画 CORE_RT
    'thicknesses_config': [2.0, 3.0],  # 第一道杆细一些
    'colors_config': ['#FF6347', '#4169E1'],  # 番茄红、皇家蓝
    'axis_config': [False, False],
    'range_config': [
        [0, 150],    # GR 范围
        [0.2, 100]   # RT 范围（对数）
    ]
}

# 多曲线叠加到同一道
config_core = {
    'core_curves': ['CORE_GR', 'CORE_RT', 'CORE_DEN'],
    'plot_index_list': [0, 0, 0],  # 都叠加在第0道
    'thicknesses_config': [2.0, 2.0, 1.5],
    'colors_config': ['#FF6347', '#4169E1', '#32CD32'],
    'range_config': [[0, 150], [0.2, 100], [2.0, 3.0]]
}
```

## 3. 绘制原理

### 3.1 叠加位置策略

岩心杆状图从曲线道的**最左侧（X 轴最小值）**开始绘制，向右延伸：

```
X 轴布局：
[0%─────────────────────────────────────────90%────100%]
|          岩心杆状图（从左侧起始）           | 空白边距 |

- 岩心杆从道最左侧 xlim[0] 开始
- 杆最大宽度为道宽的 90%
- 剩余 10% 作为右侧空白边距
```

### 3.2 杆粗细映射

杆的粗细（水平短线长度）由岩心数据值归一化决定：

```
归一化值 = (value - min) / (max - min)
杆宽度   = X轴范围 × 35% × 归一化值
```

即：值越大 → 杆越长（粗），值越小 → 杆越短（细）

### 3.3 绘制代码逻辑

```python
for depth, value in zip(depth_data, curve_data):
    if pd.isna(value):
        continue  # 跳过 NaN

    # 归一化到 [0, 1]
    norm = (value - curve_min) / (curve_max - curve_min)

    # 岩心杆从道最左侧开始
    x_start = xlim[0]
    x_width = x_range * 0.90 * norm
    x_end = x_start + x_width

    # 绘制水平短线
    ax.plot([x_start, x_end], [depth, depth],
            color=color, linewidth=thickness,
            solid_capstyle='round', zorder=10)
```

### 3.4 Z 轴层级

```python
ax.plot(..., zorder=10)  # 岩心线在曲线(zorder=5)之上
```

| 元素 | zorder | 说明 |
|------|--------|------|
| 背景 | 0 | Axes 背景 |
| 网格 | 1 | 网格线 |
| 分类条带 | 3 | 岩性分类填充 |
| FMI 图像 | 4 | 电成像图像 |
| 常规曲线 | 5 | 测井曲线 |
| **岩心杆** | **10** | 岩心短线（最上层） |
| NMR 填充 | - | 核磁填充（fill_between） |

## 4. 初始绘制 — `_plot_all_core_lines()`

### 4.1 流程


## 5. 刷新更新 — `_update_core_lines()`

### 5.1 触发时机

- 深度拖动（缩放）后，`_update_display()` 调用

### 5.2 更新策略：复用已有 Line2D 对象

为减少 Matplotlib 对象创建开销，采用**复用策略**：

```
旧线组（n_existing 条）
    │
    ├─ 逐点遍历：
    │   if 有旧线 → set_data() 更新位置
    │   else      → plt.plot() 新建
    │
    ├─ 多余旧线 → set_visible(False) 隐藏
    │
    └─ 新线 → append 到线组
```

### 5.3 为什么需要更新

深度窗口变化时：

- 新的可见深度范围 → 需要重新过滤数据点
- X 轴范围可能变化 → 归一化映射目标区间也变化

```python
# X 轴范围从 ax.get_xlim() 动态获取
xlim = ax.get_xlim()
x_range = xlim[1] - xlim[0]
x_start = xlim[0] + x_range * 0.60
```

## 6. 数据验证流程

```
logging_data DataFrame
    │
    ├─ 深度列：depth_col
    │   → 来自 config_logging['depth_col']
    │
    └─ 岩心列：core_curves[i]
        → 在 logging_data 中存在？
        │   ├─ 是 → 绘制
        │   └─ 否 → 跳过（warning 日志）
        │
        → 有有效数据（非全 NaN）？
        │   ├─ 是 → 绘制
        │   └─ 否 → 静默跳过
        │
        → 值在 range_config 范围内？
            ├─ 是 → 绘制
            └─ 否 → 跳过
```

## 7. 性能考量

| 指标 | 数值 | 说明 |
|------|------|------|
| 单条短线 | 1 次 `plot()` 调用 | 极轻量 |
| 1000 个数据点 | ~2ms 绘制 | Matplotlib 高效 |
| 内存占用 | 每条线 ~200 字节 | 可忽略 |
| 对象复用 | 深度变化时复用 Line2D | 避免 GC 压力 |

**最坏情况**：5000 个取心点 × 3 个岩心曲线 = 15000 条短线，~30ms 绘制时间，可接受。

## 9. 配置验证（data_manager.py）

在 `LoggingDataManager._validate_and_adapt_core_config()` 中执行：

```python
def _validate_and_adapt_core_config(self, config):
    # 1. 空配置检查 → 返回空
    if not core_curves: return config

    # 2. 列存在性验证 → 移除不存在的列
    valid_core_curves = [c for c in core_curves if c in columns]

    # 3. plot_index_list 智能分配
    if not plot_index_list:
        n_curves = len(self.config_logging['curves_plot'])
        plot_index_list = [i % n_curves for i in range(len(valid_core_curves))]

    # 4. thicknesses_config 补全 → 填充默认值 2.0
    # 5. colors_config 补全 → 填充默认颜色序列
    # 6. range_config 自动推断 → 从数据 min/max 推断
```
